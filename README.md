# Wazuh SOC Home Lab

## Overview

This project documents the creation of an isolated security monitoring
environment using Wazuh, Windows, Linux, and Sysmon.

The purpose of the lab is to collect endpoint security events, develop
detections, investigate simulated activity, and practice incident
documentation.

## Objectives

- Build an isolated virtual network
- Configure a Windows monitored endpoint
- Deploy a Wazuh security monitoring server
- Collect Windows and Sysmon events
- Detect suspicious activity
- Investigate alerts
- Document findings and remediation recommendations

## Planned Environment

- Windows 11 virtual machine
- Ubuntu Linux virtual machine
- Wazuh
- Sysmon
- VirtualBox
- Git and GitHub

## Planned Detections

- Repeated failed login attempts
- New user account creation
- Suspicious PowerShell execution
- Port scanning
- Security log clearing
